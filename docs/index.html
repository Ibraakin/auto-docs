Auto-Docs · adesso

Automatische Doku für dein Projekt

In vier Schritten aktivierst du für dein Repository, dass die Projektdokumentation bei jedem Pull Request automatisch mit Claude aktualisiert wird. Kein Backend, kein Hosting, keine Wartung – ein zentraler Workflow in Ibraakin/auto-docs erledigt alles.

1

Repository-Daten eingeben

Damit wir die YAML-Datei für dich generieren.

Fortgeschritten: Modell & Diff-Größe anpassen

Nur ändern, wenn du weißt was du tust. Standardwerte reichen fast immer.

2

API Key besorgen & als Secret anlegen

Jeder Entwickler kann sich seinen eigenen Key im adesso AI Hub generieren (Menü My Keys). Kostenlos im Free-Budget.

Trage ihn dann im Ziel-Repo als Secret ein:
Settings → Secrets and variables → Actions → New repository secret

Name: ADESSO_AI_HUB_KEY
Value: Dein Key aus dem adesso AI Hub (fängt mit sk- an)
3

Workflow-Datei ins Repo legen

Erstelle diese Datei in deinem Repository unter .github/workflows/update-docs.yml. Der Inhalt wird live an deine Einstellungen oben angepasst.

        öffnest, checkt der Workflow den Code aus, schickt Diff und
        vorhandene Doku an Claude und committed das Ergebnis zurück in
        den PR-Branch.
      

      

        Author des Doku-Commits: docs-bot
        

        Wenn die Doku unverändert bleibt, wird auch nichts committed.
      

      

        Erster PR nach Aktivierung: Falls die Doku-Datei
        noch nicht existiert, wird sie automatisch neu erstellt – im
        gewählten Pfad und mit einer sinnvollen Struktur aus dem Diff.
